# 🔐 Microsoft Identity & Access Management (SC-300)

This directory focuses on securing the "New Perimeter": **Identity**. These labs explore advanced features of Microsoft Entra ID (formerly Azure AD) and programmatic access control.

## 🎯 Learning Objectives
- **Identity Lifecycle:** Automating user provisioning and de-provisioning.
- **Authentication:** Conditional Access, Multi-Factor Authentication (MFA), and Passwordless.
- **Authorization:** Granular RBAC, Delegated Administration, and ABAC Conditions.
- **Governance:** Privileged Identity Management (PIM) and Access Reviews.
