# 🏗️ Azure Administration & Infrastructure (AZ-104)

This directory contains laboratories focused on building and managing the foundational infrastructure of Microsoft Azure. Understanding these core components is essential before implementing advanced Identity and Security policies.

## 🎯 Learning Objectives
- **Networking:** Virtual Networks (VNet), Subnets, Peering, and Network Security Groups (NSG).
- **Compute:** Virtual Machine deployment, configuration, and management.
- **Storage:** Storage accounts, Blob storage, and File shares.
- **Governance:** Resource Group management, Tagging, and Azure Policy.
